# AGENTS.md — инструкции для Codex

## Проект
Решение команды для хакатона HackAlem AI 2026: agentic-AI на базе OpenAI API.
Описание задачи — в `docs/idea.md`, архитектура — в `docs/architecture.md`.

## Стек и окружение
- Python 3.11+, зависимости в `requirements.txt`.
- Код — в `src/app/`, тесты — в `tests/` (pytest).
- Ключи берутся только из переменных окружения (`.env`, см. `.env.example`).

## Правила
- Никогда не хардкодить API-ключи, токены, пароли.
- Никогда не добавлять в git реальные данные (`data/` игнорируется).
  Для тестов — только синтетические данные.
- Перед завершением задачи запускать:
  - `ruff check .`
  - `pytest -q`
- Небольшие, читаемые функции; type hints; docstring у публичных функций.
- Комментарии и сообщения пользователю — на русском, идентификаторы — на английском.
