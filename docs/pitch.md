# Питч для Demo Day

Регламент по времени — уточнить у организаторов.

1. **Хук** — одна фраза о боли пользователя.
2. **Проблема** — кто, сколько теряет, почему сейчас.
3. **Решение** — что делает агент.
4. **Живое демо** — один сквозной сценарий, заранее отрепетированный. Держать запасное видео.
5. **Как устроено** — схема из `architecture.md`, где именно работает AI.
6. **Результат / метрики** — что измерили.
7. **Дальше** — внедрение, кто заказчик.
8. **Команда.**

## Чек-лист перед Demo Day
- [ ] README заполнен, ссылка на демо-видео
- [ ] Репозиторий публичный, в истории нет ключей и данных
- [ ] Демо работает с чистого `git clone`
- [ ] Запасное видео демо на случай проблем с сетью
