## Правила репозитория

- **Никаких данных и ключей в git.** `data/`, `.env`, `*.csv`, `*.xlsx` и т.п. в `.gitignore`.
  Если нужен пример данных — только синтетический, в `data/sample/` и явно помеченный.
- Коммиты — небольшие, с понятным описанием. Ветка `main` — рабочая, фичи — в `feat/*`.
- Всё, что сгенерировал Codex, проверяем глазами перед merge.
